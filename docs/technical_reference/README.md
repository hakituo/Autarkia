# 技术参考

对外发布的技术说明，描述当前实现的分层、模块职责与关键链路。
本项目采用「Python 做业务编排 + C++ 做重度计算」的混合架构，C++ 模块均带
动态检测与优雅降级，缺失时自动回退纯 Python 实现。

> 本文档集由 `scripts/doc_records/sync_tech_docs.py` 从内部技术参考生成，请勿手工编辑。
> 描述的是**当前代码**；与代码不一致时以代码为准。
