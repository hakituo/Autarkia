## 12. 性能优化指南

## 12.1 GPU显存优化

| 优化项  | 方法                | 效果      |
| ---- | ----------------- | ------- |
| 模型量化 | 使用GGUF Q4\_K\_M量化 | 显存减少50% |
| 动态卸载 | 低优先级模型自动卸载        | 避免OOM   |
| 批处理  | 合并推理请求            | 提高吞吐量   |
| KV缓存 | 启用KV缓存            | 加速生成    |
