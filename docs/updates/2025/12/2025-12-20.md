### 对话生成与云端限流优化

- **对话生成脚本重构**：`generate_dialogue_examples.py` 改造为支持“自问自答”式多轮对话生成，支持 SFW/PRIVATE 模式分流，并增加 JSONL 本地文件导出以便查阅。
- **云端 API 限速与重试**：`SiliconFlowClient` 增加 HTTP 429/403 错误检测与自动重试机制，防止因并发过高导致的 API 限流；支持可选的本地模型回退。
- **混合 LLM 模块路由**：完善 `HybridLLMModule`，支持根据 `cloud:` 前缀动态路由请求至云端或本地模型。
- **配置修复**：将 `Aveline.txt` 配置迁移至 `Aveline.json`，并更新 system prompt template 以支持 JSON 格式输出。
- **对话样本落盘优化**：JSONL 输出默认按运行时间戳拆分文件，避免每次手动改名；支持 `--tag/--output/--append` 控制输出文件名与写入方式。
- **解析与重试增强**：对模型返回的非严格 JSON（如结尾多余逗号、代码块包裹）做容错解析；生成循环按“成功条数”计数并增加最大尝试上限，避免解析失败导致条数不足或误计数。
- 修复对话生成脚本可能覆盖旧输出：当未开启 `--append` 时，输出文件名强制携带时间戳；当显式 `--output` 指定目标文件且已存在时，自动生成带时间戳的新文件名，避免清空旧文件。文件：`scripts/generate_dialogue_examples.py`
- 恢复误覆盖的云端本地人设样本：从 ChromaDB `aveline_dialogue_sfw_daily` 导出并重建 `generated_data/dialogue_examples_sfw-daily_cloud-local-persona.jsonl`（共 100 条）。
