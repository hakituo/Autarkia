## 2026-10-23（星期五）

- **下载缓慢根因定位：路径 MTU 不足 + DNS 抖动；Linux venv_cpu 安装清单与 MTU 自检脚本**
  - **背景**: Windows 3.13 离线依赖下载过程中速度反复跌至 10-45KB/s，连接与 ping 均正常。排查后确认主因是 WiFi 路径 MTU（1500 大包被丢），叠加偶发 DNS 解析失败与链路抖动。同步准备 Linux 侧 Python 3.13 的 venv_cpu 环境。
  - **根因**:
    - 路径 MTU 不足：接口 MTU=1500，但 PMTU 探测 1472/1464 全部失败、1372 通，大包被静默丢弃导致 TCP 反复重传（25KB/s）；修正后单包 12.6MB/1.6s 约 7.8MB/s
    - DNS 偶发失败：pip 下载日志出现 Failed to resolve 'mirrors.aliyun.com'，触发重试与断点续传
    - 链路质量波动：峰值 7.8MB/s 可跌至 43-156KB/s；有线网卡 enp5s0 处于 NO-CARRIER 未使用
    - GNOME 系统代理（manual 127.0.0.1:7897）不被 pip/curl 读取，代理线路实测仅 68B/s，不能作为下载通道
  - **修复**:
    - 将 zouhong_5G 与 zouhong 两个 WiFi 连接的 802-11-wireless.mtu 持久化为 1400（nmcli），重连/重启自动生效
    - 新增 scripts/tools/network_mtu_check.py：检测默认接口 MTU、PMTU 探测 1500/1400（重试 3 次规避偶发丢包）、输出临时与持久化修复命令，退出码 2 表示需要降 MTU
    - 新增 requirements/base_linux313.txt：由 base.txt 派生，剔除 onnx/onnxoptimizer（零 import 且无 cp313 轮）、memory-index-py（PyPI 无包，本地编译）、backports.asyncio.runner（py<3.11 垫片），marker 行由 pip 在 Linux 求值
    - Linux venv_cpu 使用系统 Python 3.13.15 重建并安装 base_linux313.txt 与 cpu.txt（后台执行，pip 断点续传）
  - **验证**:
    - `MTU 1400 下单包 12.6MB 耗时 1.6s（约 7.8MB/s）；network_mtu_check.py 输出接口 MTU 与 PMTU 探测结果`
    - `requirements/base_linux313.txt 有效条目 201 行，剔除项与 marker 行核对通过`
  - **备注**:
    - 若再次下载缓慢：先跑 .venv/bin/python scripts/tools/network_mtu_check.py，退出码 2 即按提示降 MTU
    - 当前链路持续波动，Linux venv_cpu 剩余依赖（opencv/paddlepaddle/torch 等）在后台继续安装；插网线（enp5s0）可绕开 WiFi 抖动
    - MTU 1400 已写入 NetworkManager 连接配置，重启后不再需要手动设置

    - datasets 5.1.0 要求 huggingface-hub>=1.31，与清单锁定的 0.36.2 冲突
    - 官方验证脚本硬编码 Windows 路径 venv_cpu/Lib/site-packages，在 Linux 直接 FileNotFoundError
  - **修复**:
    - 核心依赖手工落地：torch 2.13.0+cpu、paddlepaddle 3.3.1、onnxruntime 1.30.0、opencv 4.14.0、pyarrow 24.0.0、onnx 1.19.1（cp313 manylinux 轮），缺失小包（colorlog/colorama/sentencepiece/multiprocess/huggingface_hub/dill/xxhash）用 --no-deps 补齐避免回溯
    - paddlenlp/paddlefsl/datasets 卸载：uie_extractor 对 paddlenlp 是延迟导入且默认走 onnx 后端，卸载后 pip check 干净，UIE 仍可用 onnx 路径
    - verify_runtime_dependencies.py 的 site-packages 改为跨平台解析（Windows Lib / Linux lib/pythonX.Y），符合 RULES 双平台要求
    - Windows 离线包同步修正：base_win313.txt 恢复 onnx==1.23.2（cp312-abi3 win 轮兼容 3.13），补下载对应 wheel，规避 paddlenlp 依赖 onnx 的离线缺失
  - **验证**:

    - `冒烟 pytest（test_core_integration + test_qq_health_checker）：6 passed`

  - **备注**:
