## 2026-04-23
- **cpp_bert_engine 性能优化**：
  - **修复 Windows 中文路径加载 Bug**：原 `wstring(str.begin(), str.end())` 无法正确转换含中文的 UTF-8 路径，改用 `MultiByteToWideChar(CP_UTF8, ...)` 正确处理（如 `D:\projects\models\model.onnx`）
  - **推理 Buffer 复用**：`input_ids_` / `attention_mask_` / `token_type_ids_` 预分配为成员变量，`predict()` 中使用 `assign()` 复用内存，避免每次推理重复堆分配
- **cpp_memory_index 性能优化**：
  - **预计算向量范数**：`addRecord` 时计算并存储 `norm`，搜索时余弦相似度简化为 `dot / (query_norm × rec.norm)`，减少约 40% 浮点运算
  - **扁平连续存储**：使用 `vector<MemoryRecord>` 替代 `unordered_map`，连续内存布局大幅提升缓存命中率；另维护 `id_to_index_` 做 ID 索引
  - **显式 AVX2 内联**：余弦内积和范数计算使用 `_mm256_fmadd_ps` 显式 AVX2 指令，一次处理 8 个 float；非 AVX2 平台回退到 `#pragma omp simd`
  - **倒排索引过滤**：新增 `source_index_` / `topic_index_` 倒排索引，有 source/topic 过滤时先缩小候选集再算相似度
  - **延迟删除**：`removeRecord` 使用 `alive_[idx] = false` 标记删除，避免 vector 移动开销
