  - **背景**: 每日自动提交脚本在 git 网络操作阶段长时间无输出、进程挂起，多次运行均卡死；另因 Android 构建缓存目录未忽略导致一次需扫描 2.6 万个文件。
  - **根因**:
    - Windows 下 subprocess.run 超时只终止主进程，git 派生孙进程（git-remote-https / Git Credential Manager）继承管道句柄，communicate() 永不返回，脚本永久挂起

    - 非交互终端下 stdout 全缓冲，脚本挂起时 print 内容全部积压不显示，表现为完全无输出
  - **修复**:
    - run_cmd 超时后调用 _kill_process_tree：Windows 用 taskkill /PID /T /F 递归清理进程树，POSIX 用 killpg 杀进程组
    - git ls-remote / git push 增加 GIT_TERMINAL_PROMPT=0（认证失败立即报错不弹交互），push 另加 GCM_INTERACTIVE=never 禁用凭据管理器弹窗
    - .gitignore 增加 clients/frontend/aveline-android/android/.gradle-home/ 忽略规则
    - 脚本 main 入口 sys.stdout.reconfigure(line_buffering=True) 改为行缓冲，进度即时可见
    - QQ 号检测正则增加 (?!\.\d) 排除浮点时间戳（如 1700000000.0），消除 docstring 示例时间戳误报
