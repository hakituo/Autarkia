## 2026-05-30 修复心情一直为0 + 移除prompt直接注入状态

### 问题
1. **心情字段名错误**：`qq_peer_context.py` 中的 `_get_peer_bio_summary` 读取 `actor_state.get("mood")`，但实际存储字段是 `mood_score`，导致心情永远读不到
2. **mood_score 无限下降到 0**：当 hunger/thirst 低于阈值时，mood 每分钟 -0.6，一旦所有值降到 0 就永远无法恢复
3. **prompt 直接注入状态**：`_get_peer_bio_summary` 的结果被直接注入到 prompt 中，Aveline不需要调用工具就能看到Ling的状态

### 修复
- **字段名修正**：`qq_peer_context.py` 中 `mood` → `mood_score`
- **mood 最低保护**：`actor_manager.py` 中设置最低值 10 分，基本需求满足时 mood +0.2 缓慢恢复
- **移除 prompt 注入**：删除 `_get_peer_bio_summary` 函数调用和函数定义
- **注册 CheckPeerStatusTool**：在 `registry.py` 中注册工具，LLM 可通过工具调用按需获取对方角色状态

- `core/agents/chat_agent_components/persona_system/prompt/qq_peer_context.py`
- `core/services/life_simulation/actor_manager.py`
- `core/tools/registry.py`
