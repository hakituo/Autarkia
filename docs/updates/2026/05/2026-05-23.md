## 2026-05-23 新增 SearchChatHistoryTool + 删除 memory_recall

### 问题
Agent 在对话中"假装"查看聊天记录（如"我先看看那天的记录"），但实际上没有聊天记录查询工具。`memory_recall` 动作的 prompt 变体中包含"如果没有具体记忆，则聊一个模糊的共同感觉"，鼓励 Agent 编造回忆，与 `CORE_CONSTRAINTS` 中的"严禁编造未发生的共同经历"矛盾。

### 修改
- 新增 `SearchChatHistoryTool`（`search_chat_history`），让 LLM 能真正查询 `ChatHistoryStore` 中的原始聊天记录
  - 支持关键词搜索、日期范围过滤、角色过滤
  - 自动过滤内心独白（chat_thought），只返回用户和助手的对话
  - sfw 模式下过滤敏感内容
- 删除 `memory_recall` 从 Active Care 的可用动作列表、睡眠允许集合、安全意图列表、优先级分析合法 intent
- 删除 `ACTION_PROMPT_VARIANTS` 中的 `memory_recall` 条目
- 删除死代码：`get_relevant_long_term_memory()`、`get_long_term_memory()`、`long_term_memory` 字段
- 在 `prepare_active_tools` 中添加 `search_chat_history` 的关键词激活逻辑

## 2026-05-23 新增生词测验工具（WordQuizTool）

### 功能
- AI 可以从 `unfamiliar_word.txt` 生词本中随机抽取单词，逐个询问用户是否认识
- 用户不认识时，单词后的数字自动+1；认识时数字-1（最低为0）
- 支持三种优先策略：`high_count`（优先抽不认识次数多的）、`random`（完全随机）、`new`（优先抽未测验的）
- 支持 quiz（抽题）、mark_unknown（不认识+1）、mark_known（认识-1）、list（列出所有）、stats（统计）操作
- **主动推送**：维护循环每小时检查一次，每天自动推送一次生词测验通知

### 修改
- 新建 `core/tools/study/english/word_quiz_tool.py`（WordQuizTool 工具类）
- `core/tools/study_tools.py`：注册 WordQuizTool
- `core/services/study/catalog.py`：添加 word_quiz 工具元数据
- `core/services/study/persona/study_persona_profile.py`：添加生词测验引导提示
- `core/services/study/service.py`：添加 english/word_quiz 路由
- `core/agents/chat_agent_components/study.py`：添加"生词""背单词"等触发关键词
- `core/services/active_care/vocabulary.py`：新增 `check_daily_word_quiz` 方法
- `core/services/active_care/service.py`：在维护循环中调用每日生词测验推送

## 2026-05-23 修复 WeightedMemory 保存权重数据 WinError 5 拒绝访问

### 问题
- `save_weighted_data_locked` 保存权重数据时，`os.replace` 原子替换因 `[WinError 5] 拒绝访问` 失败
- 原因：Windows 上杀毒软件/索引器锁定目标文件，原重试策略等待时间过短（约1.9秒）

### 修复
- 重试次数从6次增加到10次，指数退避总等待约25秒
- 原子替换最终仍失败时，回退到直接写入目标文件（非原子但保证数据不丢失）

### 修改
- `memory/core/persistence.py`：增强 `_retry_os_replace` 和 `safe_json_dump`

## 2026-05-23 优化 Active Care Prompt 去人机味

### 问题
- active care 主动关怀生成的消息太人机，例如"你们这个世界，晚上不学习的话，都干啥啊？"
- 根因：prompt 模板中存在"对人类世界表现出强烈的好奇心"、"你们人类为什么喜欢喝咖啡？"等引导性措辞
- 带引号的词如"学到"、"观察"、"体感"、"环境感知"也会让模型生成时带出人机味

### 修复
- `curious_question`：去掉"人类世界"相关措辞，改为"像朋友闲聊时突然好奇"，明确禁止"你们人类/你们这个世界"
- `gossip_share`：去掉"网络世界（其实是你的数据流）"这种出戏描述
- `share_thought`：去掉带引号的"学到"、"观察"、"看到"
- `weather_complaint`：去掉"模拟的'环境感知'"、"CPU太热蒸桑拿"等，改为自然表达
- `CORE_CONSTRAINTS`：新增第7条，严禁使用"你们人类"、"你们这个世界"等异世界生物说法

### 修改
- `core/agents/chat_agent_components/persona_system/prompt/active_care_prompts.py`
