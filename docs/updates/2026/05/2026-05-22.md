## 2026-05-22 Active Care 话题冷却机制修复

### 问题
Active Care 连续多条主动推送都在聊同一个话题（如油耗/加油），用户多次变换话题后系统仍然不切换。原因是话题冷却机制存在4个Bug：
1. `TopicKeywords` 只定义了 SLEEP/GREETING/CARE 三个类别，"油耗/加油"等话题被分类为 "other"
2. `check_topic_cooldown` 对 "other" 类别直接放行，不检测重复
3. `build_topic_diversity_constraint` 没有通用兜底警告，未知类别返回空字符串
4. **严重隐藏Bug**：`detect_topic_category` 返回大写类别名（如 `SLEEP`），但 `build_topic_diversity_constraint` 的 alternatives 字典 key 用的是小写（如 `sleep`），导致**所有话题多样性警告从未生效**

### 具体改动

1. **扩展 TopicKeywords** (`core/services/active_care/constants.py`)
   - 新增 `VEHICLE` 类别：车、加油、油耗、92、95、油站、斯巴鲁等关键词
   - 新增 `FOOD` 类别：吃、饭、美食、外卖、和牛、海鲜等关键词
   - 新增 `STUDY` 类别：学习、作业、考试、复习等关键词

2. **修复 check_topic_cooldown** (`core/services/active_care/prompt_builder.py`)
   - 新增 `_compute_keyword_overlap()` 函数，基于2-gram containment系数计算文本相似度
   - 对 "other"/"unknown" 类别，用关键词重叠检测替代直接放行
   - 当连续3条以上消息与当前候选消息重叠率≥0.25时，触发冷却

3. **添加通用兜底话题多样性警告** (`core/agents/chat_agent_components/persona_system/prompt/active_care_prompts.py`)
   - 新增 `TOPIC_DIVERSITY_VEHICLE_WARNING`：车/加油话题单调警告
   - 新增 `TOPIC_DIVERSITY_FOOD_WARNING`：食物话题单调警告
   - 新增 `TOPIC_DIVERSITY_STUDY_WARNING`：学习话题单调警告
   - 新增 `TOPIC_DIVERSITY_GENERIC_WARNING`：通用兜底警告（任何话题重复时触发）

4. **更新 build_topic_diversity_constraint** (`core/services/active_care/prompt_builder.py`)
   - 映射表新增 VEHICLE/FOOD/STUDY 三个类别（大写，与 detect_topic_category 返回值一致）
   - 修复 alternatives 字典 key 大小写不匹配的隐藏Bug（之前 sleep/greeting/care 全部小写，导致从未匹配）
   - 对 "other"/"unknown" 类别返回 `TOPIC_DIVERSITY_GENERIC_WARNING` 兜底

## 2026-05-22 修复 transformers 5.x AutoTokenizer 多线程导入失败

### 问题
AvelineService 后台初始化时，在 `asyncio.to_thread` 线程池中导入 `from transformers import AutoTokenizer` 间歇性失败，报 `ImportError: cannot import name 'AutoTokenizer' from 'transformers'`。

### 原因
transformers 5.x 使用 `_LazyModule` 延迟加载机制，`AutoTokenizer` 等类不在 `__init__.py` 中直接导出，而是通过 `__getattr__` 动态加载。在多线程环境下（`asyncio.to_thread`），`_LazyModule` 的延迟加载存在竞态条件，导致偶尔找不到属性。

### 修复
将所有 `from transformers import AutoTokenizer` 改为直接从子模块导入 `from transformers.models.auto.tokenization_auto import AutoTokenizer`，绕过 `_LazyModule` 机制。同理修复了 `AutoModelForCausalLM` 和 `AutoModelForVision2Seq` 的导入。

- `core/services/data_ops/bert_runtime_mixin.py`
- `core/core_engine/model_manager.py`
- `core/modules/llm/sync_generator.py`
- `core/modules/llm/model_loader.py`
- `core/model_adapter.py`
