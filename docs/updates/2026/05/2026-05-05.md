## 2026-05-05
- **🐛 修复 Active Care do_nothing 直接返回跳过 force_send 兜底 + _is_override_allowed non_response 完全阻止覆盖**：
  - `proactive_checker.py:_build_priority_and_select_action()`: do_nothing 时先调用 `should_force_send` 检查，如果 force_send=True 则继续 LLM 决策流程，不再直接 return

- **✨ 新增 Active Care 推断睡眠模式（probable_sleep）：用户未说晚安时深夜长时间无响应自动推断入睡**：
  - `proactive_checker.py`: 新增 `_try_infer_probable_sleep()` 方法，当用户深夜（0-6点）2h+或早上（6-10点）3h+无响应且无晚安时，自动进入 `probable_sleep` reduced mode；支持清醒信号退出和14h自动退出

  - `constants.py`: 新增 `PROBABLE_SLEEP_*` 常量；`build_sleep_status_description()` 新增 probable_sleep 描述；`build_quiet_mode_instruction()` 新增 probable_sleep 指令

  - `decision.py`: 时间约束在 `probable_sleep` 模式下不再建议 `should_send=false`，改为允许发送轻量探针
  - `service.py:_reset_interaction_state()`: 用户发消息时自动退出 `probable_sleep` 模式
