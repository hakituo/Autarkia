- **进程工具优化：扩展黑名单+AI自身标注**
  - **背景**: check_running_processes 工具显示的进程太多，Windows常驻系统进程混杂其中，不够清晰
  - **修复**:
    - 基于实际进程查询结果扩展 `_SYSTEM_PROCESSES` 黑名单：

      - 云存储（nutstoreclient.exe、nutstoredriversvc.exe、nutstore_watchdog.exe）

## 2026-07-16（周四）

- **修复 /wake 后角色仍被判定为 overslept_recovery（DND）导致消息静默累积**
  - **背景**: 用户 /wake 唤醒玲后发消息，reply_policy 仍判定 dnd_sleeping_silent(activity=overslept_recovery, ac_sleeping=False)，角色不回复。日志显示 sleep_manager.phase 已是 fully_awake，但 character_daily.plan.current_activity 仍停留在 overslept_recovery。
  - **根因**:
    - engine._update_current_activity 中 overslept 检查（原 line 308-310）只看 sleep_summary.overslept 标记，不看 phase
    - overslept 标记一旦设置只在跨天时清除，/wake 后 phase 已变成 fully_awake/night_awake，但 overslept 仍为 True
    - OVERSLEPT_RECOVERY 在 DO_NOT_DISTURB_ACTIVITIES 集合中，触发 reply_policy 走 DND 静默累积分支
  - **修复**:
    - engine.py _update_current_activity：在 overslept 检查时增加 phase 判断，phase 为 fully_awake/night_awake 时不进入 OVERSLEPT_RECOVERY 分支
    - phase 变量提前计算复用给后续 fully_awake DND 槽位覆盖逻辑，避免重复代码
    - tests/character_daily/test_sleep_activity_override.py 新增 3 个回归测试覆盖 fully_awake/night_awake/waking_up 三种 phase × overslept=True 场景
    - 顺手修复 test_force_wake_and_interrupt.py / test_manual_interrupt_window.py / test_message_deferral.py 中 mock_engine 缺少 refresh_current_activity return value 导致的回归测试失败（reply_policy 检测到 DND 时会调用 refresh_current_activity 强制刷新）
  - **验证**:
    - `venv_core\Scripts\python.exe -m pytest tests/character_daily/test_sleep_activity_override.py -v`
    - `venv_core\Scripts\python.exe -m pytest tests/character_daily/test_force_wake_and_interrupt.py tests/character_daily/test_manual_interrupt_window.py tests/unit/test_life_sleep_wake_route.py -v`
  - **备注**:
    - 历史 lesson 已记录 /wake 后 plan.current_activity 残留 sleeping 的问题（已通过 refresh_current_activity 修复），但 overslept 标记残留是另一条独立路径，本次修复补全该盲区
    - 剩余的 test_message_deferral.py 中 test_busy_force_interrupt_at_hard_threshold / test_dnd_active_care_sleeping_alone_triggers_defer 等失败与本修改无关，是 cooking 已移到 soft_delay、active_care 状态判定逻辑变更等已存在的测试与代码不同步问题
