  - **修复**:
    - 在 persona_system/prompt/ye 下建立 core、voice、overlay、knowledge、runtime、semantic memory 与 episodic memory 分层目录，并保留旧 core_ye 与 Ye_QQ_Master 作为故障回退
    - 新增 ye_layered_prompt.py，通过稳定 meta.scope=ye 选择专用链路；静态层固定为 conversation policy、core、voice，动态层按显式覆盖、非空当前状态、主题知识和本地记忆顺序生成
    - private overlay 只由 ongoing_interaction.mode=private 激活，称呼本身不触发；当前状态问题跳过稳定外貌和日常资料
    - 叶的私密覆盖层、当前状态和运行时记忆加入本机私有忽略规则，其他角色和通用 Prompt 组装保持原路径
    - 修正 QQ 相对 persona 路径识别，避免平台清理逻辑误改分层 JSON 中的括号内容

    - `.\venv_core\Scripts\python.exe -m ruff check 相关 Prompt 与验证文件（通过）`
