## 2026-03-29（完善LLM缓存键生成：智能忽略动态内容 + 客户端类型识别）

- 问题描述：
  - 用户反馈缓存命中率很低，命中缓存只有未命中缓存的一半
  - 虽然用户聊天只发几个字，但token消耗却很高
  - 初步修复只考虑了时间锚点，但还有其他动态内容（如QQ客户端约束）
- 深度分析：
  - 发现系统中有多处动态注入的系统消息：
    - **【时间锚点】**：每次都包含当前系统时间（动态）
    - **【QQ 输出硬约束】**：根据客户端类型动态注入
    - **【角色扮演强化指令】**：根据分级模式动态注入
    - **【Private Memories】**：私密记忆内容动态变化
    - **【思考库】**：思考记忆内容动态变化
    - **【历史摘要】**：历史压缩内容动态变化
    - **【相关记忆回溯】**：RAG检索内容动态变化
    - **【更早对话压缩】**：压缩内容动态变化
- 修复内容：
  - **OpenAIClient** ([openai_client.py](file:///d:/AI/xiaoyou-core/core/llm/openai_client.py))
    - 重新设计 `_generate_cache_key()` 方法，智能识别并忽略动态内容
    - **动态内容忽略策略**：
      - 忽略【时间锚点】（时间每次都不同）
      - 忽略【Private Memories】（私密记忆动态变化）
      - 忽略【思考库】（思考记忆动态变化）
      - 忽略【历史摘要】（历史压缩动态变化）
      - 忽略【相关记忆回溯】（RAG检索动态变化）
      - 忽略【更早对话压缩】（压缩内容动态变化）
    - **客户端类型识别**：
      - 检测【QQ 输出硬约束】判断是否为QQ客户端
      - QQ客户端：保留QQ约束，QQ客户端之间可以共享缓存
      - 非QQ客户端：忽略QQ约束，非QQ客户端之间可以共享缓存
    - **静态内容保留**：
      - 保留【硬性输出约束】（静态约束）
      - 保留【角色扮演强化指令】（根据模式固定）
      - 保留用户消息和助手回复
  - **新增测试脚本** ([test_cache_key_generation.py](file:///d:/AI/xiaoyou-core/tests/test_cache_key_generation.py))
    - 测试时间锚点被忽略
    - 测试客户端类型检测
    - 测试静态内容相同生成相同缓存键
    - 测试不同内容生成不同缓存键
    - 测试不同参数生成不同缓存键
    - 测试混合动态内容
- 验证结果：
  - ✓ 时间锚点被忽略：通过
  - ✓ 客户端类型检测：通过
  - ✓ 静态内容相同生成相同缓存键：通过
  - ✓ 不同内容生成不同缓存键：通过
  - ✓ 不同参数生成不同缓存键：通过
  - ✓ 混合动态内容：通过
- 预期效果：
  - 缓存命中率大幅提升（不再因为动态内容变化而无法命中）
  - 相同对话内容直接从缓存返回，无需调用API
  - QQ客户端和非QQ客户端分别缓存，避免混淆
  - 显著降低token消耗

## 2026-03-29（BERT ONNX模型加载速度优化：embeddings缓存机制）

- 问题描述：
  - BERT ONNX模型加载需要5-6秒，影响启动速度
  - 主要瓶颈：初始化时需要运行100+次ONNX推理来计算各类原型embeddings
- 优化内容：
  - **Embeddings缓存机制** ([bert_analyzer.py](file:///d:/AI/xiaoyou-core/core/services/data_ops/bert_analyzer.py))
    - 新增 `_get_cache_key()` 方法：基于定义内容生成唯一缓存key
    - 新增 `_load_embeddings_from_cache()` 方法：从缓存加载embeddings
    - 新增 `_save_embeddings_to_cache()` 方法：保存embeddings到缓存
    - 新增 `_load_list_embeddings_from_cache()` 方法：加载List类型embeddings
    - 新增 `_save_list_embeddings_to_cache()` 方法：保存List类型embeddings
    - 缓存目录：`cache/bert_embeddings/`
  - **ONNX Session优化**
    - 设置 `intra_op_num_threads = 4`
    - 设置 `inter_op_num_threads = 4`
    - 启用 `graph_optimization_level = ORT_ENABLE_ALL`
  - **新增测试脚本** ([test_bert_loading_speed.py](file:///d:/AI/xiaoyou-core/tests/scripts/test_bert_loading_speed.py))
- 优化效果：
  - 首次加载（计算embeddings）：~30秒（与之前相同）
  - 缓存加载：**~0.6秒**（优化前~6秒，提升约10倍）
  - 缓存文件大小：约2MB
