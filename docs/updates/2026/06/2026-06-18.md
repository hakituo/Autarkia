## 2026-06-18 修复 Prompt Cache 命中率低 + 时间戳后处理剥离

### Prompt Cache 修复
- **根本原因**：`dialogue_injection`（对话示例）基于 VectorSearch 语义匹配，每条不同消息匹配不同示例，但被拼在 `static_part`（system 消息）中，导致 system 消息每次都变，DeepSeek 前缀匹配缓存完全失效
- **修复**：将 `dialogue_injection` 从 `static_part` 移到 `dynamic_part`（user 消息前缀），确保 system 消息只包含纯静态人设，100% 稳定可缓存
- **修改文件**：`core/agents/chat_agent_components/persona_system/prompt/assembler.py`

### 时间戳后处理剥离
- **根本原因**：原有正则 `\d{2,4}-\d{2}-\d{2}` 要求两个 `-` 分隔符，无法匹配 `[05-22 01:45]`（一个 `-`）和 `[23:10]`（无日期部分），导致时间戳剥离从未生效
- **修复**：重新设计正则 `\[(?:\d{2,4}(?:-\d{2}){1,2}\s+)?\d{2}:\d{2}(?::\d{2})?(?:\s*\([^)]+\))?\]\s*`，支持 `[HH:MM]`、`[MM-DD HH:MM]`、`[YYYY-MM-DD HH:MM]` 三种格式
- **四层防护**：streaming.py（后处理+流式前缀）、handler.py（后处理）、qq_adapter_session.py（发送前）、qq_adapter_transport.py（兜底）
- **共享函数**：`qq_adapter_utils.py` 新增 `strip_ai_timestamp()`
- **调试日志**：streaming.py 和 qq_adapter_session.py 中添加时间戳剥离日志
