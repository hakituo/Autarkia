## 2026-06-19 Active Care 阶段 A 八轨道拆分重构

从 8 个大文件中拆出 17 个新模块，每个源文件保留转发方法保持向后兼容：

1. **activity_detector.py → activity_maps.py**：活动映射表（进程名/窗口标题分类）
2. **decision.py → decision_output_parser.py + decision_instruction_builder.py**：决策输出解析（JSON 修复、regex fallback）+ 决策指令构建
3. **postprocessor.py → sleep_sanitizer.py + deduplicator.py + leak_detector.py**：睡眠净化器 + 去重器 + 泄露检测器
4. **prompt_builder.py → prompt_context_builders.py + topic_diversity.py**：Prompt 上下文构建 + 话题多样性控制
5. **priority_analyzer.py → daily_push_priority.py + portrait_keyword_map.py**：每日推送优先级 + 画像关键词映射
6. **decision_executor.py → action_builder.py + context_gatherer.py**：动作构建器 + 上下文采集器
7. **context.py → conversation_resolver.py + schedule_config_loader.py**：会话 ID 解析 + 作息配置加载
8. **peer_script_generator.py → peer_script_dispatch.py + peer_script_hooks.py**：剧本分发 + 后处理钩子

**DRY 优化**：`portrait_keyword_map.py` 合并了 `decision.py` 和 `priority_analyzer.py` 中的重复关键词映射
