## 架构设计

### 调度流程

```
┌─────────────────────────────────────────────────────────────┐
│                    Task Submission                          │
└─────────────────────────┬───────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                  GlobalTaskScheduler                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              Priority Queue                          │   │
│  │  CRITICAL > HIGH > MEDIUM > LOW                     │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              Task Type Router                        │   │
│  │  DEFAULT → Async Pool                               │   │
│  │  CPU_BOUND → Thread Pool                            │   │
│  │  GPU_BOUND → GPU Lock + C++ Engine                  │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────┬───────────────────────────────────┘
                          │
          ┌───────────────┼───────────────┐
          │               │               │
          ▼               ▼               ▼
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│ Async Pool  │   │ Thread Pool │   │ C++ Engine  │
│ (IO Tasks)  │   │ (CPU Tasks) │   │ (GPU Tasks) │
└─────────────┘   └─────────────┘   └─────────────┘
```

### C++调度引擎架构

```
┌─────────────────────────────────────────────────────────────┐
│                    CPPSchedulerEngine                        │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐   │
│  │              ResourceIsolationScheduler              │   │
│  │  - 任务队列管理                                      │   │
│  │  - 资源隔离                                          │   │
│  │  - 优先级调度                                        │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                  GPULLMWorker                        │   │
│  │  - GPU资源管理                                       │   │
│  │  - 模型加载/卸载                                     │   │
│  │  - 推理执行                                          │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              BiologicalState                         │   │
│  │  - 神经递质状态                                      │   │
│  │  - 能量/睡眠债务                                     │   │
│  │  - 认知延迟计算                                      │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```
